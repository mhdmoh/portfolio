## Notes

From 2021 to 2025 I built Flutter and native apps for enterprise clients as a senior mobile developer. My main public work from that time is [redacted](https://pub.dev/packages/redacted), a Flutter package that generates loading skeletons from your existing widgets. It has 55 stars on GitHub.

The move into AI was an evolution of that foundation, not a restart:

```flow
Production software engineering
Architecture
Debugging
Release discipline
Performance
AI systems
```

What carried over wasn't a framework. It was release discipline, debugging under pressure, and keeping shared code small: I extract it the third time I repeat something. Those habits still decide how I design RAG pipelines, scoring systems, and enterprise integrations.
